# 绘图素材：供修改 PPT / 报告使用

直接打开 **[index.html](index.html)** 预览全部图，再选择需要的格式。可以把整个 `deliverables/figure_assets/` 文件夹复制给组员，离线预览不依赖 Python、网络或训练模型。

- `png/`：11 张 PNG，最适合直接插入 PowerPoint、Keynote、WPS。优先使用 `slides_*`，文字和布局已经按展示场景调整。
- `pdf/`：对应的 11 张矢量 PDF，适合 LaTeX、打印和支持 PDF 的排版软件；放大更清晰。需要改变曲线、字体或误差条时，应从数据重新绘图。
- `manifest.json`：每个副本的原始来源、SHA-256 和文件大小；素材与正式报告图逐字节相同。

## 图名与用途

| 图 | 文件名（不含扩展名） | 现有位置 | 内容 |
| --- | --- | --- | --- |
| 展示用学习曲线 | `slides_learning` | PPT：第 5 页 | 七个配置的平均验证代价，纵轴为对数；越低越好。 |
| Clip range 消融 | `slides_clip` | PPT：第 7 页 | clip=0.1/0.2/0.3 对回报、越界率和电量的影响。 |
| GAE lambda 消融 | `slides_lambda` | PPT：第 8 页 | lambda=0.90/0.95/0.99 对回报、越界率和电量的影响。 |
| Epochs 消融 | `slides_epochs` | PPT：第 9 页 | epochs=5/10/20 对回报、越界率和电量的影响。 |
| 冷天闭环轨迹 | `slides_cold_trace` | PPT：第 10 页 | 默认 PPO seed 0 与恒温器的室温及累计电量；固定条件 test_cold_00。 |
| 完整与后期学习曲线 | `learning_curves` | 报告：第 6 页 | 上排展示完整训练，下排放大 102,400 步后的变化；阴影为跨种子标准差。 |
| 舒适度与电量权衡 | `comfort_energy_tradeoff` | 报告：第 7 页 | 横轴为七天电量，纵轴为越界率；含恒温器参考，未画关闭空调。 |
| PPO 更新诊断 | `update_diagnostics` | 报告：第 8 页 | 近似 KL 与裁剪比例；跨种子均值后进行五次更新移动平均。 |
| 三类天气闭环轨迹 | `representative_trajectories` | 报告：第 9 页 | 室温、外温、动作与累计电量；默认 PPO seed 0 和恒温器使用相同条件。 |
| 完整物理指标比较 | `test_metrics` | 补充：中文解读 | 三个参数分别比较 CVR、越界度时和电量；可用于拆分或扩展结果页。 |
| 训练耗时比较 | `runtime` | 补充：中文解读 | 训练墙钟时间扣除周期评价；误差条为跨种子标准差。 |

## 使用时保留的说明

所有结果来自每配置 3 个训练种子、每种子 512,000 个交互步。最终测试先对每个模型的 30 个条件求均值，再跨 3 个训练种子求均值和样本标准差。误差条和学习曲线阴影表示训练种子的标准差；不是置信区间。

回报越高越好；越界率 CVR、越界度时、用电量越低越好。展示用学习曲线画的是 **负回报（代价，对数纵轴）**，因此越低越好。电量单位为 **kWh / 七天回合**，不是平均功率。更新诊断图已经做五次更新移动平均，其他图不要额外平滑后仍沿用原说明。

原始绘图入口在 `hvac_ppo/analysis.py`，数据在 `results/*.csv`；`results/README.md` 说明各表字段。此目录是供展示编辑使用的副本，正式报告仍引用 `results/figures/`。

## 更新素材

重新汇总绘图后，在仓库根目录执行：

```bash
python scripts/export_figure_assets.py
```

此命令仅复制已有图、核对副本哈希并更新说明和预览页，无需重跑训练或安装额外依赖。手工改图请另存文件，避免下次同步覆盖。
